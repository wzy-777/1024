# 项目规则

## 项目概述

《锦鲤 · 天机舆图》——一个纯前端的"数据大屏"式小游戏：九处水脉节点持续汇聚欧气，玩家点击节点源/目标，指挥锦鲤搬运 1 点欧气，凑满九点即"鲤跃龙门"，按用时计成绩。

仓库当前只有一个游戏成品：

| 文件 | 说明 |
| --- | --- |
| `koi-fortune-map.html` | 唯一成品，单文件自包含（约 1586 行，内联 CSS + Canvas + 原生 JS） |
| `微信图片_20261024172257_50_399.png` | 该界面的效果截图（视觉基准参考） |
| `.trae-html-share-packages/koi-fortune-map.html.zip` | 分享用的打包副本，不进代码修改流程 |

原《最后一次带路》叙事 Demo 及其文稿、演示稿、分享包已按用户要求删除，不要恢复或引用。

## 技术约束

- **零依赖、可离线**：单个自包含 HTML，CSS/JS 内联，不引 CDN、不建构建流程、不用框架。
- 不要拆文件、不要引入打包工具，除非用户明确要求。
- JS 为 `(() => { 'use strict'; ... })()` 单 IIFE，使用 `const`/`let`、箭头函数、模板字符串（由浏览器直接支持，无转译）。
- 兼容 `file://` 直接打开；不依赖 fetch、模块化或本地服务器。
- 文案简体中文；保留英文小字副标题（如 `FORTUNE INDEX`）以维持大屏质感。

## 代码结构（`koi-fortune-map.html`）

按区块组织，改动前先定位对应区块：

- **舞台**：`#stage` 固定 1920×1080，`fitStage()` 按窗口等比缩放，`resize` 时同步 `layout()`。
- **数据**
  - `NODE_DEFS` — 9 个节点：`昆仑墟/龙门/瑶池/蓬莱/云梦泽/白泽池/沧澜海/桃都/归墟`，坐标为画布比例 `x/y ∈ [0,1]`。
  - `EDGE_DEFS` + `EDGE_OFF` — 14 条连线及贝塞尔弯曲偏移；`NEIGH` 由边推导出邻接表。
  - `SLIPS` — 天机签文池；`KOI_PALETTE` — 锦鲤配色；`KOI_TOTAL = 7`。
- **状态** `S` — `luck / running / finished / startAt / elapsed / attempts / best / selSrc / slipNo / muted`。
- **核心规则**
  - `computeMultipliers()` — 相邻两点同值则双方 ×2；某点与全部邻点同值则该点与邻点 ×4。
  - `stepGrowth(dt)` — 每节点基础 `0.5 × mult` 点/秒，累加到 100 封顶。
  - `selectNode(i)` / `commandTransfer(src, dst)` — 先点源、再点目标；锦鲤 `toSrc → toDst` 飞行后 `applyTransfer()` 执行 −1 / +1。
  - 九点全满 → `finishRun()` → 结算浮层"鲤跃龙门"，用时与最快纪录写入 `localStorage`（`koiTrial.best` / `koiTrial.tries`）。
- **表现层**：`frame(now)` 主循环驱动 `drawKoi()`、`drawSlip()`、粒子 `parts`、涟漪 `ripples`、飘字 `floats`；`tone()` 为 WebAudio 合成音效，`#soundBtn` 切换静音。
- **辅助逻辑**：`tickClock()` 时钟每秒刷新；`#ticker` 跑马灯；`addLog()` 事件流最多保留 7 条。

## 数值与口径

- 9 节点 × 每点 100 = 满溢；单次搬运固定 1 点。
- 基础增长 0.5 点/秒，倍率 1 / 2 / 4。
- 记录键名与设置项保持不变，避免破坏玩家本机纪录。
- 改节点数、边或倍率规则时，必须同时检查 `NEIGH`、`mult`、HUD 文案（"九点满溢"）与节点面板列表是否仍一致。

## 改动原则

1. **视觉保持"科技蓝大屏"**：深色底（`#01050b` 系）、青色主色 `#4fe3ff` 系、金色高亮 `#ffd166`；兼顾扫描线、网格、辉光。不要引入新的主色或大块亮色。
2. **左右面板是信息板，不是按钮区**：左侧欧气总览/节点矩阵，右侧签文/事件流；中间画布是唯一交互区。
3. 文案短、克制、带一点赛博调侃（如"转发此锦鲤，Bug 不沾身。"），不要写成说明书。
4. 所有动画在 `requestAnimationFrame` 主循环内驱动，动效应可叠加在低帧率下自洽；不要引入外部动画库。
5. 不做无关重构；只改用户要求的部分。新增音效/字体/外链需先确认。

## 验证方式

- 直接双击或在浏览器打开 `file://` 验证，重点看 1920×1080 缩放与窗口适配。
- 关键路径自测：点节点开局 → 选源选目标 → 锦鲤搬运动画与数值变化 → 倍率 ×2 / ×4 出现 → 九点满溢出结算 → "再试一次"完整重置。
- 交互边界：源点欧气为 0、目标点已满、源目标相同、锦鲤全忙，均应有事件流提示且不崩。
- 改过 `localStorage` 相关逻辑后，刷新页面确认最快纪录与尝试次数仍能正确读取。
